# Banking Portal – Project Statement

## 1. Problem Statement

Traditional banking operations require users to perform tasks such as checking account details, depositing or withdrawing money, and transferring funds through banking systems. Managing these operations manually can be time-consuming and may lead to errors.

The **Banking Portal** aims to provide a simple and secure digital system where users can manage their bank accounts and perform basic banking operations through APIs. The system uses Java and Spring Boot to handle user authentication, account management, and transactions.

## 2. Scope of the Project

The scope of the Banking Portal includes:

* User registration and login.
* Secure authentication using JWT tokens.
* Managing account PINs.
* Viewing account details and balance.
* Depositing money into an account.
* Withdrawing money from an account.
* Transferring money between accounts.
* Viewing transaction history.
* Storing and managing banking data using MySQL.
* Handling common errors using global exception handling.

The project mainly focuses on the **backend/API development** of a basic banking system.

## 3. Target Users

The Banking Portal is mainly designed for:

* **Bank Customers:** To manage their accounts and perform basic banking operations.
* **Banking Staff/Admin:** To manage and monitor banking-related information.
* **Developers/Students:** To understand how banking APIs, authentication, databases, and transactions can be implemented using Java and Spring Boot.

## 4. High-Level Features

### User Management

* User registration
* User login
* User authentication using JWT
* View user details

### Account Management

* View account details
* Create account PIN
* Check PIN
* Update PIN
* Check account balance

### Banking Operations

* Cash deposit
* Cash withdrawal
* Fund transfer
* Transaction history

### Security & Error Handling

* JWT-based authentication
* Protected API endpoints
* Unauthorized access handling
* Account not found handling
* Insufficient balance handling
* Global exception handling

### Database

* MySQL database for storing user, account, and transaction information.
